# 飞行检查单编写与校验工具（sologsb-1030）

用于按飞行阶段编写、校验、复核和冻结操作检查单。项目实现完整的数据模型、本地持久化、版本控制、快捷键、拖拽排序、校验、修订差异与打印导出。

## 功能

- 阶段与检查项：维护飞行阶段、挑战语、预期回应、关键标记、前置条件和异常处置。
- 快速录入：可使用 `/` 聚焦挑战语，`Cmd/Ctrl+Enter` 新增检查项，`Alt+↑/↓` 调整当前项位置。
- 拖拽排序：检查项可拖动并跨阶段移动，阶段也可调整先后顺序。
- 发布校验：
  - 重复挑战语与高频回应；
  - 缺少挑战语或预期回应；
  - 自引用、已删除或顺序不可达的前置条件；
  - 飞行阶段顺序异常；
  - 空阶段提示。
- 发布流程：编辑中 → 复核中 → 冻结；存在阻断错误、未处理的并发冲突或顺序变化后未重新核对可达性时，不能提交复核或冻结。
- 多标签页并发控制：
  - 编辑租约：同一检查单同一时刻只允许一个页面写入，持有者每 5 秒续租、15 秒无心跳自动失效，关闭页面即释放，其他页面只读并可申请接管。
  - 版本核对：保存前对比项目内容版本与逐项版本号，检测他页已写入，自动做字段级三方合并。
  - 失效保护：租约失效的旧页面只能查看并重新确认，重新获得租约时合并其未落盘修改；刷新不会丢弃这些修改。
  - 冲突挂起：同一检查项被两页改到同一字段（含都调顺序）时互不覆盖、挂起人工处理；处理完成前禁止提交复核。
  - 可达性重算：任一页面改变检查项顺序（含跨阶段拖动、删除）都会标记需要重新核对，确认前禁止复核和冻结。
- 修订控制：冻结后可创建新修订；冻结快照保留阶段、检查项、时间和复核说明。
- 版本差异：可选择当前版本或任意冻结版本作为基准与比较版本，显示新增、删除、修改和阶段调整。
- 键盘与历史：支持撤销、重做、手动保存，最近 40 次编辑可回退。
- 离线保存：所有数据写入浏览器 `localStorage`。
- 只读预览与打印：提供对话框预览、浏览器打印/PDF，以及独立打印版 HTML 导出。

## 技术栈

- React 19
- TypeScript 5
- Radix Themes
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`。宿主机正式端口由根目录 `docker-compose.yml` 映射为 `10030:80`，源码不硬编码宿主端口。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1030 .
docker run --rm -p 10030:80 sologsb-1030
```

多阶段镜像构建完成后由 nginx 监听容器 `80`，只提供静态前端资源。

## 数据说明

浏览器存储键为 `sologsb-1030-workspace-v1`（检查单数据，含项目内容版本、检查项/阶段版本、待处理冲突与顺序待核对标记），编辑租约存于 `sologsb-1030-lease-v1`，主题偏好使用 `sologsb-1030-theme`。当前版本内置 C172 示例检查单及两个历史冻结版本。
